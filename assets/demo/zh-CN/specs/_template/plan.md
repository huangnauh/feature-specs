## 4. 验证与回滚

- [ ] 记录外部服务、环境、版本、测试数据和变更范围
- [ ] Targeted gate：每个 operation/切片运行最小且相关的软件包或组件检查
- [ ] Batch gate：仅在批次风险或本 plan 要求时运行相关仓库检查和 smoke；纯文档批次不运行代码检查
- [ ] Stage/final gate：每个 plan 定义的 delivery stage 和最终交付各运行一次昂贵全仓检查；最终阶段的一次运行可同时满足两者
- [ ] Rerun trigger：依赖/生成物、runtime wiring、并发、协议/事实源边界、实质代码、工具链或环境变化，证据过期、先前失败/flaky，或用户/CI 明确要求时重跑昂贵 gate
- [ ] 运行要求的集成、E2E、兼容性或人工验证
- [ ] 验证回滚，或记录为何不需要
